# 🚀 متجر نوفا ستور الإلكتروني المتكامل (NovaStore Pro eCommerce)

منصة تجارة إلكترونية متكاملة واحترافية قابلة للتشغيل والإنتاج والتطوير المباشر، مبنية بأحدث معايير هندسة البرمجيات باستخدام **Laravel + MySQL / SQLite**، مع واجهة متجر فائقة السرعة تدعم الوضعين العربي (RTL) والإنجليزي (LTR)، وتعدد العملات، وبوابات الدفع والشحن، ونظام التسويق بالعمولة (Affiliate)، ولوحة تحكم إدارية (Admin Dashboard) متقدمة مع مخصص مظهر حي (Live Theme Customizer).

---

## 🌟 أبرز الميزات والوظائف المكتملة

### 1. واجهة المتجر (Storefront)
* **الصفحة الرئيسية التفاعلية**: شريط ترويجي أعلى الصفحة، بانرات Hero متحركة، بطاقات الميزات، شبكة الأقسام، قسم عروض الفلاش سيلز مع عداد تنازلي، قائمة المنتجات الأكثر مبيعاً والمميزة، وقسم الماركات والنشرة البريدية.
* **كتالوج المنتجات والفلترة المتقدمة**: فلترة شاملة حسب الأقسام، الماركات، نطاق الأسعار، التقييم، توفر المخزون، مع تحويل فوري بين العرض الشبكي (Grid) والعرض القائمي (List)، وخيارات الترتيب (الأحدث، السعر، التقييم، الأكثر طلباً).
* **البحث الفوري (Live Search Auto-complete)**: اقتراحات بحث حية وسريعة مع إظهار الصورة والسعر وحالة التوفر.
* **صفحة تفاصيل المنتج الكاملة**: معرض صور تفاعلي مع زووم، فيديو المنتج، محدد الخصائص والمتغيرات (المقاس، اللون، السعة)، حساب السعر ونسبة الخصم، عداد الكمية، أزرار الشراء الفوري والإضافة للمفضلة والمقارنة، والمشاركة عبر (واتساب، X، فيسبوك، ونسخ الرابط).
* **نظام التقييمات والمراجعات**: إمكانية إضافة مراجعة وتقييم بالنجوم مع شارة المشتري الموثق.
* **سلة المشتريات (Cart)**: تعديل الكميات الفوري، حذف المنتجات، تطبيق كوبونات الخصم، وحساب الضرائب والشحن تلقائياً.
* **إتمام الطلب (Checkout)**: إدخال بيانات التوصيل، اختيار طريقة الشحن، واختيار بوابة الدفع (الدفع عند الاستلام، تحويل بنكي، بطاقة ائتمان، PayPal).
* **تتبع الطلبات (Order Tracking)**: صفحة عامة لتتبع مراحل الطلب خطوة بخطوة بالرقم والبريد.
* **قائمة المفضلة والمقارنة**: حفظ المنتجات ومقارنة المواصفات جنباً إلى جنب.

### 2. اللغات والعملات
* **تعدد اللغات (Multi-language)**: دعم كامل للغة العربية بجميع اتجاهات ومحاذاة الـ **RTL**، والإنجليزية **LTR**، مع إمكانية إضافة لغات وترجمات جديدة من لوحة التحكم.
* **تعدد العملات (Multi-currency)**: دعم الريال السعودي (SAR)، الدولار الأمريكي (USD)، الدرهم الإماراتي (AED)، اليورو (EUR)، والجنيه المصري (EGP)، مع تحديث أسعار الصرف تلقائياً وتحديد العملة الافتراضية.

### 3. حساب العميل (Customer Hub)
* لوحة تحكم العميل، سجل الطلبات السابقة، تفاصيل الفاتورة، تعديل الملف الشخصي وكلمة المرور، إدارة المرتجعات، ومركز التسويق بالعمولة.

### 4. نظام التسويق بالعمولة (Affiliate System)
* توليد رابط إحالة مخصص لكل عميل (`?ref=CODE`)، تتبع الكوكيز والزيارات، حساب عمولات الشراء تلقائياً، وسجل أرباح وسحوبات.

### 5. نظام المرتجعات والاسترجاع (Return & Refund)
* تقديم طلب استرجاع مع تحديد السبب، التفاصيل، ورفع صور للمنتج، مع مسار موافقة واعتماد من الإدارة.

### 6. لوحة التحكم الإدارية (Admin Dashboard)
* **إحصائيات ورسوم بيانية**: إجمالي المبيعات، عدد الطلبات، الطلبات المعلقة، الأرباح الصافية، رسم بياني تفاعلي للمبيعات (Chart.js)، والمنتجات الأكثر مبيعاً وتنبيهات نقص المخزون.
* **إدارة الكتالوج**: إضافة وتعديل وحذف المنتجات، رفع صور متعددة، الأقسام، الماركات، الكوبونات، والعروض.
* **إدارة الطلبات والمبيعات**: استعراض الطلبات، تعديل الحالات، وإصدار وطباعة فواتير ضريبية رسمية (Printable Invoice).
* **مخصص المظهر المباشر (Theme Customizer)**: تحكم كامل في الشعار، الألوان الرئيسية والثانوية، نوع الخط، شكل الأزرار، وبانرات المتجر مع معاينة حية فورية.
* **مراقبة الزوار الحية**: عداد وسجل الزوار المتواجدين الآن في المتجر، الصفحات، والأجهزة مع حماية الخصوصية.
* **سجل الأنشطة (Activity Logs)**: تتبع كافة عمليات وتعديلات المدراء.

## 💻 طريقة التشغيل السريعة (Quick Start Guide)

### الطريقة 1: التشغيل بنقرة واحدة عبر السيرفر الداخلي (موصى بها)
1. افتح موجه الأوامر (PowerShell أو CMD) في مسار المشروع:
   ```bash
   cd C:\Users\elnou\.gemini\antigravity\scratch\ecommerce-store
   ```
2. قم بتشغيل خادم التطوير:
   ```bash
   php -S localhost:8000 -t public public/index.php
   ```
   أو عبر ملف التشغيل السريع:
   ```cmd
   run.bat
   ```
3. افتح المتصفح وتوجه إلى:
   * **واجهة المتجر**: `http://localhost:8000`
   * **لوحة التحكم**: `http://localhost:8000/admin/login`

---

### الطريقة 2: التشغيل عبر XAMPP أو Laragon أو Apache
1. انسخ مجلد `ecommerce-store` إلى مسار `htdocs` (في XAMPP) أو `www` (في Laragon).
2. اجعل مسار الـ Document Root يشير إلى مجلد `public`.
3. إذا كنت ترغب باستخدام قاعدة بيانات **MySQL**:
   * افتح ملف `.env` وقم بتعديل الإعدادات:
     ```env
     DB_CONNECTION=mysql
     DB_HOST=127.0.0.1
     DB_PORT=3306
     DB_DATABASE=ecommerce_store
     DB_USERNAME=root
     DB_PASSWORD=
     ```
   * قم بإنشاء قاعدة بيانات باسم `ecommerce_store` في phpMyAdmin أو MySQL Workbench.
   * سيقوم التطبيق بإنشاء الجداول والبيانات التجريبية تلقائياً عند أول تشغيل، أو يمكنك تشغيل:
     ```bash
     php artisan migrate --seed
     ```

## 📂 الهيكل البرمجي للمشروع (Project Architecture)

```
ecommerce-store/
├── app/
│   ├── Controllers/     # Storefront, Admin, Customer, Auth, and API controllers
│   ├── Core/            # Database, Model, Router, View, Request, Response, Auth, Session, Helper
│   ├── Middleware/      # Auth, Admin, Locale/Currency, Visitor, PriceVisibility
│   ├── Models/          # 25+ Eloquent-style Models
│   └── Services/        # Cart, Order, Payment, Shipping, Affiliate, SEO, VisitorTracker
├── config/              # App, Database, and eCommerce settings
├── database/
│   ├── migrations/      # Complete SQL Schema tables with Foreign Keys
│   └── seeders/         # Bilingual realistic demo data
├── lang/
│   ├── ar/              # Arabic translations (RTL)
│   └── en/              # English translations (LTR)
├── public/
│   ├── assets/          # CSS, JS, Fonts, and Icons
│   ├── uploads/         # Uploaded products, brands, and categories images
│   └── index.php        # HTTP Kernel entry point
├── resources/views/     # Blade template views (storefront, admin, customer, auth)
├── routes/              # Web, Admin, and API routes
├── artisan              # CLI tool for migrations and server
├── .env                 # Environment configurations
├── run.bat              # One-click Windows runner
└── setup.bat            # One-click database initializer
```

## 🛡️ الأمان وحماية البيانات
* حماية متكاملة ضد هجمات **CSRF** عبر الرموز المشفرة.
* تشفير وحماية كلمات المرور باستخدام خوارزميات `BCRYPT / ARGON2`.
* حماية كاملة ضد **SQL Injection** عبر Prepared Statements و Parameterized Queries.
* تعقيم وحماية مدخلات النصوص ضد **XSS**.
* حماية وتشفير وتحديد أنواع الصور المرفوعة وتحجيمها آلياً.
* سجل تدقيق شامل لأنشطة المدراء في لوحة التحكم.
